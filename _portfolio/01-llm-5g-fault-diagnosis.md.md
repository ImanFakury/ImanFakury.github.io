*B.S. Thesis supervised by Prof. Babak Khalaj — Aug. 2025 – June 2026* · [Thesis PDF](/files/BS_Thesis_5G_LLM.pdf)

* Deployed a 5G Core and RAN simulation environment using **OpenAirInterface** and **UERANSIM** as Kubernetes workloads.
* Built a **Chaos Mesh** fault-injection pipeline targeting 5G Core, RAN, and UE pods to generate a multi-component system log dataset.
* Proposed **SHEPR**, an optimization-based prompt-engineering method that iteratively refines prompts using an optimizer LLM and extracted protocol knowledge to guide a baseline LLM in 5G fault detection.
